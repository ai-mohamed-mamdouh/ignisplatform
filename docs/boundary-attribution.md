# Administrative boundary attribution

The platform redistributes ADM1 source geometries obtained through geoBoundaries gbOpen. Geometry is packaged as compressed WKB and repaired where required for spatial validity. A simplified GeoJSON derivative is included for display. Full dataset metadata and upstream download URLs accompany the corresponding country in `assets/boundaries/`.
